I've been playing with [remotion](https://www.remotion.dev/), a React framework that essentially transforms your IDE into a video editor. I've only scratched the surface with it so far and am already equal parts awed and horrified by how easy remotion makes it for Claude Code (or any other AI agents) to generate videos.

We're going to start in the shallow end with a basic Tiktok-style video featuring a series of static slides with a voice over, captions and a friendly jingle.

You can easily figure out all of this by exploring the very [detailed docs](https://www.remotion.dev/docs/) on the remotion website together with your coding agent. However, you will still want to know how the pieces fit together, especially since letting agents do what ever they want leads to messy architecture.
